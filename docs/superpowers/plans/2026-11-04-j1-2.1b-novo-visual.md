# 2.1b Novo visual — Plano de implementação

> **Para agentes:** SUB-SKILL OBRIGATÓRIA: use superpowers:subagent-driven-development (recomendada) ou superpowers:executing-plans para executar este plano tarefa por tarefa. Os passos usam caixas de seleção (`- [ ]`) para acompanhamento.

**Objetivo:** trocar os dois painéis do 2.1 por um painel de fichas e uma tela própria para cada ficha, no visual "Moderno com alma gótica".

**Arquitetura:**
- só o frontend muda; a API fica como está;
- o painel filtra e conta no navegador, sobre o `GET /fichas`, usando funções puras testadas à parte;
- o shell vira só um topo fixo e um `<router-outlet>`; o serviço `Layout` (BreakpointObserver) e os componentes `FichaLista` e `FichaInicio` saem, e seus testes migram para o painel e o shell;
- a ficha troca as abas por blocos e passa a usar dois componentes novos: `Medalhao` (iniciais sobre degradê) e `AnelStatus`.

**Stack:** Angular 22.2 (standalone, signals, zoneless), Angular Material 22.2.5 (`MatMenu`, `MatTooltip`), Vitest 5 + jsdom, `@fontsource/eb-garamond` 5.3.0.

**Spec:** `docs/superpowers/specs/2026-11-04-j1-redesign-design.md` (§2 linha 2.1b, §3 inteira). Leia também o plano do 2.1 (`2026-11-04-j1-2.1-frontend-novo.md`), porque as correções de lá continuam valendo.

**Comandos** (rodados em `frontend/`; no PowerShell use `npm.cmd`, sem alterar a política de execução):
- testes: `npm.cmd test -- --watch=false`;
- build: `npm.cmd run build`.

## Restrições globais

- A API não muda, e o `FichaEntrada` enviado continua igual.
- Tokens da spec §3.5:
  - `--cor-fundo #0b0a0f` + névoa `radial-gradient` com `rgba(88,52,110,.38)`;
  - `--cor-superficie #121019`;
  - `--cor-borda #262031`;
  - `--cor-borda-dourada rgba(201,164,92,.42)`;
  - `--cor-texto #e6e1d6`;
  - `--cor-texto-suave #8a8296`;
  - `--cor-titulo #f0e2bf`;
  - `--cor-acao #c9a45c`;
  - `--cor-vida #e0604b`;
  - `--cor-sanidade #57c49a`.
- Fonte dos títulos e nomes: EB Garamond 400 e 600, subconjunto latino, via `@fontsource/eb-garamond@5.3.0` (versão exata). Nomes com `font-variant-caps: small-caps`. O texto corrido usa a fonte do sistema. Nenhuma fonte ou script vem de CDN.
- Ferido = `vidaAtual ≤ vidaMaxima / 2`; sanidade baixa = `sanidadeAtual ≤ sanidadeMaxima / 2`. Uma ficha sem o atual, sem o máximo, ou com máximo ≤ 0 não é nenhum dos dois.
- A busca procura em `personagem` e `jogador`, sem diferenciar maiúsculas e acentos.
- Grade do painel: 1 coluna; 2 a partir de 600 px; 3 a partir de 900 px.
- Perícias: as 23, na ordem do catálogo. A barra vai até `min(valor, 100)%` e a marca do extremo fica em `faixas(valor).extremo %`. Uma perícia sem valor conta como 0, fica esmaecida e continua rolável.
- `aria-label` do rolar: `Rolar {nome}, {valor}`, com valor 0 quando ausente. O retrato só aparece no 2.1c.
- As dicas "ⓘ" ficam só em `button.dica` com `matTooltipTouchGestures="off"` (correção do 2.1).
- Alvos de toque têm pelo menos 44 px, o foco visível é dourado e os textos passam no contraste AA.
- Orçamentos do `angular.json` (inicial 500 kB de aviso; estilo por componente 4 kB de aviso): os estilos repetidos vão para `styles.scss`, não para cada componente.
- Nenhum teste é apagado sem destino: cada teste que sai migra ou é reescrito conforme o **mapa de testes** abaixo, e o mapa vai no PR.

## Foco da revisão

1. **Busca ou filtro que não acham nada:** o painel diz "Nenhuma ficha encontrada" e oferece "Limpar filtros". Não pode mostrar o convite de "criar a primeira ficha" (Tarefa 4).
2. **Valores que estouram:** vida atual maior que a máxima, ou perícia acima de 100. A barra e o anel ficam limitados a 100% e o número aparece como está (Tarefas 3 e 5).
3. **Nome com espaços extras ou com uma palavra só:** as iniciais não podem sair vazias nem com espaço (Tarefa 3).
4. **Excluir pelo menu ⋮:** o `MatMenu` abre num overlay fora do componente. A confirmação continua obrigatória e o bloqueio de clique duplo do 2.1 continua valendo (Tarefa 5).
5. **Voltar do formulário para o painel:** a lista recarrega depois de criar, editar ou excluir. Hoje quem faz isso é a `versaoFichas`, e o painel precisa observá-la como a lista fazia (Tarefa 4).
