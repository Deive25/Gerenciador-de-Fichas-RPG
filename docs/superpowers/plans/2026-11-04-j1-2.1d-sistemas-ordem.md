# 2.1d Esqueleto de sistemas + Ordem Paranormal — Plano de implementação

> **Para agentes:** SUB-SKILL OBRIGATÓRIA: use superpowers:subagent-driven-development (recomendada) ou superpowers:executing-plans para executar este plano tarefa por tarefa. Os passos usam caixas de seleção (`- [ ]`) para acompanhamento.

**Objetivo:** trocar o sistema d100 por um esqueleto de vários sistemas, com uma tabela por sistema (herança JPA JOINED), e entregar **Ordem Paranormal completa**. As fichas que já existem viram Ordem.

**Arquitetura:**
- a migração V4 renomeia `sheet_player` → `ficha` (dados comuns e `sistema`) e cria `ficha_ordem` e `ficha_ordem_pericia`, convertendo as fichas antigas;
- a API recebe e devolve fichas polimórficas pelo campo `sistema`, a listagem devolve um resumo, `PATCH /fichas/{id}/recursos` faz a edição rápida e `POST /fichas/{id}/testes` rola os d20 de Ordem com o `Dado` injetável;
- no front, o painel passa a usar o resumo, a ficha e o formulário viram os de Ordem, e `/fichas/nova` começa pela escolha do sistema (D&D "em breve");
- o código e os testes do d100 saem, listados no mapa de testes.

**Stack:** Java 21, Spring Boot 4.1.2, Hibernate 7 (`@Inheritance(JOINED)`, `@DiscriminatorColumn`), Jackson 3 (`@JsonTypeInfo`/`@JsonSubTypes`, cujas anotações continuam em `com.fasterxml.jackson.annotation`), Flyway, PostgreSQL 17, Testcontainers; Angular 22.2, Material 22.2.5, Vitest 5.

**Spec:** `docs/superpowers/specs/2026-11-04-j1-sistemas-design.md` (§2 linha 2.1d, §3.1, §3.2, §4, §5, §6.1, §6.3, §7, §8). O retrato (2.1c) e a edição rápida continuam valendo: a edição rápida troca o `PUT` pelo `PATCH`.

**Comandos:**
- backend, em `Gerenciador de fichas RPG/`: `.\mvnw.cmd -B clean verify` (precisa do Docker; pare a API local antes, porque o `clean` apaga o `target/`);
- frontend, em `frontend/`: `npm.cmd test -- --watch=false` e `npm.cmd run build` (PowerShell, `$env:NG_CLI_ANALYTICS='false'`).

## Restrições globais

- **Valores do sistema:** `sistema` vale `ORDEM_PARANORMAL` (e `DND` no 2.1e). No 2.1d, um `POST` com `"sistema": "DND"` dá 400 (subtipo desconhecido).
- **Atributos de Ordem:** códigos e nomes `AGI` Agilidade, `FOR` Força, `INT` Intelecto, `PRE` Presença, `VIG` Vigor. Valor de 0 a 5, e os 5 são obrigatórios.
- **NEX:** de 5 a 99, obrigatório.
- **Classe:** `COMBATENTE`, `ESPECIALISTA`, `OCULTISTA` ou nula (o front mostra "A definir").
- **Graus:** `TREINADO` (+5), `VETERANO` (+10, exige NEX ≥ 35) e `EXPERT` (+15, exige NEX ≥ 70). Sem entrada = destreinado (+0).
- **As 28 perícias (código → nome → atributo), exatas:**
  - `ACROBACIA` Acrobacia AGI, `ADESTRAMENTO` Adestramento PRE, `ARTES` Artes PRE, `ATLETISMO` Atletismo FOR, `ATUALIDADES` Atualidades INT, `CIENCIAS` Ciências INT, `CRIME` Crime AGI;
  - `DIPLOMACIA` Diplomacia PRE, `ENGANACAO` Enganação PRE, `FORTITUDE` Fortitude VIG, `FURTIVIDADE` Furtividade AGI, `INICIATIVA` Iniciativa AGI, `INTIMIDACAO` Intimidação PRE, `INTUICAO` Intuição PRE;
  - `INVESTIGACAO` Investigação INT, `LUTA` Luta FOR, `MEDICINA` Medicina INT, `OCULTISMO` Ocultismo INT, `PERCEPCAO` Percepção PRE, `PILOTAGEM` Pilotagem AGI, `PONTARIA` Pontaria AGI;
  - `PROFISSAO` Profissão INT, `REFLEXOS` Reflexos AGI, `RELIGIAO` Religião PRE, `SOBREVIVENCIA` Sobrevivência INT, `TATICA` Tática INT, `TECNOLOGIA` Tecnologia INT, `VONTADE` Vontade PRE.
- **Teste de Ordem:**
  - quantos d20: o valor do atributo; com atributo 0, rola 2;
  - qual dado fica: o maior; com atributo 0, o menor;
  - total = mantido + bônus do grau (perícia) ou + 0 (atributo).
  - `modo` diferente de `NORMAL` → 400; `alvo` `SALVAGUARDA` → 400.
- **Recursos de Ordem:** `PV`, `SAN`, `PE`, com `atual` e `maximo` ≥ 0 (opcionais). O `PATCH` aceita só os atuais desses três códigos.
- **Erros:** ProblemDetail em português.
  - **400** "Dados inválidos" com `errors` por campo;
  - **409** "Sistema não muda" ("O sistema de uma ficha não muda.");
  - **404** "Ficha não encontrada".
- **JSON estrito:** continua; o `id` no corpo continua aceito e ignorado.
- **Nada de texto dos livros:** as dicas "ⓘ" das perícias são descrições curtas escritas com palavras próprias.
- **Mapa de testes:** os testes do d100 saem de propósito e os de comportamento que continua são reescritos. O mapa vai no PR.

## Foco da revisão

1. **Migração com dados reais:** ficha com retrato, ficha com `lifem`/`sanm` nulos e ficha sem perícias. Nada some além do que a spec manda e os ids não mudam, porque o retrato e as URLs dependem deles (Tarefa 2).
2. **Grau incompatível com o NEX** (Veterano com NEX 30), também no `PUT` que **baixa o NEX** de uma ficha que já tem Veterano: 400 com a mensagem no campo `pericias` (Tarefas 3 e 7).
3. **Rolagem com atributo 0:** rola 2d20 e mantém o **menor**, mesmo numa perícia em que a pessoa é Expert. O total é o menor + 15 (Tarefas 1 e 4).
4. **Edição rápida de um recurso sem máximo** (PE vazio nas fichas convertidas): o **+** não fica travado e o `PATCH` só manda o código mudado (Tarefa 6).
5. **Abrir `/fichas/{id}/editar` de uma ficha convertida** (classe nula, PE vazio): o formulário carrega e salva sem exigir a classe (Tarefa 7).
